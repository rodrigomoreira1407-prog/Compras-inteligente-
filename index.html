🔗 Integração com Bling

Conecte sua conta Bling para importar automaticamente contas a receber, a pagar e clientes. Seus dados já cadastrados no Bling serão carregados.

🔑 Conectar com Bling
✅ Conectado ao Bling — token OAuth2 ativo. Seus dados serão carregados automaticamente.
📊 Importar Planilha de Produtos (Bling CSV)

Importe diretamente a planilha de produtos exportada do Bling. Os itens serão cadastrados ou atualizados automaticamente no sistema.

Como exportar do Bling:
1. No Bling, acesse Produtos → Todos os Produtos
2. Clique em Exportar → Exportar CSV
3. Salve o arquivo e clique no botão abaixo para importar
☁️ Backup e Sincronização entre dispositivos

Exporte seus dados para um arquivo e importe em qualquer computador ou celular para manter tudo sincronizado.

Como usar em outro computador:
1. Clique em Exportar — salva um arquivo .json com todos seus dados
2. Leve esse arquivo (pendrive, e-mail, WhatsApp) para o outro dispositivo
3. Abra o sistema lá e clique em Importar dados
4. Selecione o arquivo .json — tudo será restaurado automaticamente
⚠ Zona de Perigo

Esta ação não pode ser desfeita. Faça um backup antes.
