═══════════════════════════════════════════════════════════
  COMO INICIAR O SISTEMA
═══════════════════════════════════════════════════════════

  ➤ Dê DUPLO CLIQUE no arquivo:  INICIAR.bat

  O sistema vai abrir automaticamente no seu navegador.
  Não feche a janela preta enquanto estiver usando.

═══════════════════════════════════════════════════════════
  REQUISITO: NODE.JS
═══════════════════════════════════════════════════════════

  Se aparecer erro "Node.js não encontrado":

  1. Acesse: https://nodejs.org
  2. Clique em "LTS" (versão recomendada)
  3. Instale normalmente (Next → Next → Finish)
  4. Reinicie o computador
  5. Tente abrir o INICIAR.bat novamente

  Node.js é gratuito e não interfere em outros programas.

═══════════════════════════════════════════════════════════
  CONFIGURAR INTEGRAÇÃO COM BLING (FAZER UMA VEZ)
═══════════════════════════════════════════════════════════

  Antes de usar a integração, crie o arquivo bling.config.json
  na mesma pasta deste sistema:

  1. Copie o arquivo  bling.config.example.json
  2. Renomeie a cópia para  bling.config.json
  3. Abra o arquivo bling.config.json com o Bloco de Notas
  4. Substitua os valores:
       "clientId":     coloque seu Client ID do Bling
       "clientSecret": coloque seu Client Secret do Bling

  Onde encontrar o Client ID e Client Secret:
    → Bling → Menu usuário → Aplicativos → seu app → editar

  ⚠ NUNCA envie bling.config.json para o GitHub.
    Ele está no .gitignore e só ficará na sua máquina.

═══════════════════════════════════════════════════════════
  INTEGRAÇÃO COM BLING — USO DIÁRIO
═══════════════════════════════════════════════════════════

  1. Inicie o sistema pelo INICIAR.bat (obrigatório)
  2. Vá em ⚙ Configurações → Integração com Bling
  3. Clique em "🔑 Conectar com Bling"
  4. Faça login no Bling e autorize o aplicativo
  5. Você será redirecionado de volta para o sistema
  6. Clique em "🔄 Sincronizar com Bling"

  ✅ Todos os seus dados já cadastrados no Bling (clientes,
     contas a receber e a pagar) serão importados automaticamente.
     Não é preciso re-cadastrar nada!

  O token OAuth2 é salvo em bling.token.json e renovado
  automaticamente. Você só precisa se conectar uma vez.

  ⚠ A integração só funciona quando o sistema é aberto
    pelo INICIAR.bat (http://localhost:3000).

═══════════════════════════════════════════════════════════
  USAR EM OUTRO COMPUTADOR
═══════════════════════════════════════════════════════════

  Opção 1 — Pendrive:
    Copie toda esta pasta para o pendrive.
    No outro computador, instale o Node.js e execute INICIAR.bat.
    Refaça a conexão com o Bling nas Configurações.

  Opção 2 — Backup de dados:
    No sistema: ⚙ Configurações → Exportar todos os dados
    Leve o arquivo .json e importe no outro computador.
